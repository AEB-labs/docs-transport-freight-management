AEB has tested and approved many popular printer models for you to easily set them up in Carrier Connect without further clarification. 
In the <a href="https://rz3.aeb.de/docudata/system-requirements/carrier-connect/systemreq-carrierconnect-aebcloud/en-US/499954827499959563.html">Carrier Connect (AEB Cloud) system requirements</a> you can find out which printers have been approved.

If your printer is not included in the list, <a href="https://service.aeb.com/hc/en-us/requests/new">enter a request in the AEB Help Center</a>.
