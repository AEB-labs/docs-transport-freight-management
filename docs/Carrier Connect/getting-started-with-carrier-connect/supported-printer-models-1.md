Carrier Connect supports the preparation of labels for printing on thermal printers as well as PDF output. Please note that the API only returns the label as a print stream in the requested printer language or a PDF.

The handover of the labels to the printer must be carried out by the receiving client system or you can use the AEB print agent for output to your printer. 

Please note: Not all printer languages and resolutions are supported by all carriers. Restrictions on the use of certain printer languages, PDF printing, and print resolutions can be found in the service description of the respective carrier.
