Items can be added either using <a href="https://carrierconnect.docs.developers.aeb.com/docs/create-shipment" target="_blank">createShipment</a> or <a href="https://carrierconnect.docs.developers.aeb.com/reference#processshipment-1" target="_blank">processShipment</a>. 
Of course, a combination of both is also possible.

When adding items using *processShipment*, it could be necessary to <a href="https://carrierconnect.docs.developers.aeb.com/docs/update-shipment-data-1" target="_blank">update</a> some other shipment values e.g. customs value or goods value.
