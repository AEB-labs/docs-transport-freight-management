## Playing around with the API

If you just want to play around with the API Methods of Carrier Select, you can use one of the following options.

## Readme.io

* Go to the [API Reference](https://transport-freight-management.docs.developers.aeb.com/reference/createroutingtask) of this documentation and navigate to the *Carrier Select* section.
* Authenticate yourself by entering "*user*@*client*" and your password into the auth popup, right next to the *try it* button.

## Swagger

* Authenticate yourself by clicking the Authorize button at the top of the page.
* Go to the [Swagger UI of the demo engine](https://rz3.aeb.de/demo1routing/swagger/).
* Navigate to the RoutingBFBean section of the page for the Carrier Select methods.

## Manually setting up the API

The Carrier Select API methods can be found at: 

## REST (OpenApi)

`*ENGINE_URL*/rest/openapi.json` (e.g. `https://rz3.aeb.de/demo1routing/rest/openapi.json`)

## SOAP

`*ENGINE_URL*/servlet/bf/RoutingBF?WSDL` (e.g. `https://rz3.aeb.de/demo1routing/servlet/bf/RoutingBF?WSDL`)

For Authentication see: [REST Authentication](https://transport-freight-management.docs.developers.aeb.com/v2/docs/setup-your-environment-1#section-rest-authentication)
